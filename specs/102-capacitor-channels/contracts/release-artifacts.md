# Contract: Release Artifacts & Version Sync

## Version sync (one source)

- `scripts/release/version.js` remains the ONLY version source (spec 076).
- `scripts/native/sync-native-config.js` writes, from it:
  - Android `versionName` = semver; `versionCode` = `major*1_000_000 + minor*1_000 + patch`.
  - iOS `CFBundleShortVersionString` = semver; `CFBundleVersion` = same derivation.
  - `frontend/capacitor.config.ts` (tenant appId/name from the manifest,
    cohort from the build env).
- `scripts/native/check-native-versions.js` regenerates and diffs; a hand
  edit to any synced field fails CI. Run in the same gate group as the
  existing regenerate-and-diff checks.

## Release pipeline (spec-076 workflow extension)

- New jobs on the release workflow, ALL gating (no `continue-on-error`):
  - `android-artifact`: assemble the web build (tenant default, mainnet
    cohort), `cap sync android`, Gradle `bundleRelease`, sign with the upload
    key delivered via the spec-097 secret mechanism (registry id + tfvars
    grant added together; a missing credential fails the job naming the
    secret, never skips signing silently). Output: `.aab` + sha256.
  - `ios-artifact` (macOS runner): same web build, `cap sync ios`,
    `xcodebuild archive` + unsigned export. Output: zipped archive + sha256.
    Signing + store upload are the operator ceremony
    (`docs/runbooks/native-release-operations.md`).
  - `native-smoke-android` (emulator) and `native-smoke-ios` (simulator):
    install the built artifact's debug twin, assert launch → sign-in gate
    visible → one live read surface rendered → background/foreground past the
    lock threshold re-prompts. Failure fails the release.
- The chore(release) record PR's table gains one row per native artifact:
  `channel`, `artifact`, `sha256`, `signed` (see data-model). A record row may
  ONLY describe an artifact whose build and smoke jobs passed on that tag.

## Dependency rules (spec 075)

- Capacitor core/CLI/platform/plugin packages are added with
  `npm run deps:reinstall`, pinned EXACT, and `check:deps` + both byte gates
  must pass on the PR that introduces them (mini-app output bytes are
  keccak-committed — a hoisting change that moves them is a deliberate
  baseline re-record, not a chore).
- The native shells (`frontend/ios/`, `frontend/android/`) are committed
  generated code: regenerated by tooling, edited by hand only where Capacitor
  documents an owner hook, and version fields never by hand (gate above).
